DOUBLE TAKE FRAMES DESIGN RELEASE 2.0.3
Released 2026-09-04

Prepared-project printability correction.

CHANGES
- Oriented the clock-string guide flat using the transform from its prepared
  individual 3MF project.
- Restored actual generated support for both capstans, beyond retaining their
  painted support regions.
- Re-packed the plate without changing object orientation and successfully
  sliced all seven objects with Bambu Studio's non-interactive slicer.
- Carried the frame-and-stand project and editable OpenSCAD geometry forward
  unchanged.

COMPATIBILITY
This packaging-only patch does not change printed-part geometry or
compatibility. Users who downloaded Everything Else 2.0.2 should replace it
with 2.0.3. The 2.0.x capstans and clock-string guide remain a coordinated pair;
do not mix either part with its 1.x counterpart.

KNOWN DOCUMENTATION NOTE
The general how-it-works video may still show the earlier weight mechanism. The
current written assembly instructions govern.

VERSIONING
This project follows Semantic Versioning 2.0.0: https://semver.org/
MAJOR = incompatible printed-part or hardware interface change.
MINOR = backward-compatible new part, option, or substantial improvement.
PATCH = backward-compatible geometry, tolerance, documentation, or packaging fix.
