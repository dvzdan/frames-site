DOUBLE TAKE FRAMES DESIGN RELEASE 2.0.2
Released 2026-09-04

Native Bambu project packaging hotfix.

CHANGES
- Replaced the invalid hand-assembled Everything Else 2.0.1 package with a
  native Bambu Studio project containing the current roller, dry-wall rig,
  clock-string guide, capstans, latch, and keeper meshes.
- Preserved the prepared capstan, dry-wall-rig support enforcer, object
  placements, Bambu Lab A1 0.4 mm nozzle profile, 0.20 mm process, manual
  supports, and snug support style.
- Verified the repaired project by loading and slicing all six intended objects
  through Bambu Studio's non-interactive slicer.
- Carried the frame-and-stand project and editable OpenSCAD geometry forward
  unchanged.

COMPATIBILITY
This packaging-only patch does not change printed-part geometry or
compatibility. Users who downloaded Everything Else 2.0.1 should replace it
with 2.0.2. The 2.0.x capstans and clock-string guide remain a coordinated pair;
do not mix either part with its 1.x counterpart.

KNOWN DOCUMENTATION NOTE
The general how-it-works video may still show the earlier weight mechanism. The
current written assembly instructions govern.

VERSIONING
This project follows Semantic Versioning 2.0.0: https://semver.org/
MAJOR = incompatible printed-part or hardware interface change.
MINOR = backward-compatible new part, option, or substantial improvement.
PATCH = backward-compatible geometry, tolerance, documentation, or packaging fix.
